# 侧边导航

一个轻量的 Chrome 扩展，在网页右侧中部显示导航工具栏。

## 功能

- 直达页面顶部
- 向上翻一页（保留 120px 阅读上下文）
- 向下翻一页（保留 120px 阅读上下文）
- 直达页面底部
- 隐藏工具栏，并通过右侧小标签随时恢复
- 自动适配深色模式和“减少动态效果”系统设置

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 打开页面右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目文件夹 `navbar`。
5. 打开或刷新任意 HTTP/HTTPS 网页，工具栏会出现在页面右侧中部。

Chrome 内部页面（例如 `chrome://extensions/`）不允许扩展注入脚本，这是浏览器的安全限制。

## 多语言

扩展名与描述会跟随 Chrome 界面语言自动切换：中文显示「侧边导航」，英文显示「SideNav」。文案位于 `_locales/zh_CN` 与 `_locales/en` 下的 `messages.json`。

## 开发验证

```powershell
npm install
npm test
```

扩展使用 Manifest V3，不申请浏览器权限，也不会读取或发送页面数据。
